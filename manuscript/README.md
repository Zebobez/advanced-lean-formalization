# Manuscript workspace

The Markdown master is organized by part under `chapters/part-NN/`. `SUMMARY.md` is the chapter order and `FrontMatter.md` contains the introduction. The original source tree was left untouched when this copy was staged.

**Do not add unpublished manuscript content while this GitHub repository is public.** Before doing so, change its visibility under **GitHub repository Settings → General → Danger Zone → Change repository visibility** and verify the repository is private.

Keep chapter source files as plain text where practical; commit only files you have permission to distribute. Publisher rights and prepublication policies have not yet been decided.

## Editing and synchronization

Edit the chapter files in this repository as the working copy and update `SUMMARY.md` when changing the book's order. The examples generator reads that index and writes only complete top-level Lean commands to `Book/Chapters/`; contextual proof fragments remain in the manuscript until they can be placed in a complete example.
