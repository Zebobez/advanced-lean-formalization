## How to use the book

Read the chapters in order or use the table of contents to jump to a technique. Work through the exercises by first predicting the proof state Lean should produce, then checking that prediction in Lean. The examples assume Mathlib unless a chapter says otherwise.

The book has twenty-four overarching Parts, each grouping related Chapters. Inside a chapter, semantic section headings break the main technique into short subchapters. The numbered sections, worked examples, failure modes, and exercises are designed to be readable independently as well as in sequence.

The source is plain Markdown. Lean code appears in fenced code blocks. For mathematical notation, use `\\( ... \\)` inline and `\\[ ... \\]` for display equations. These delimiters work in both the mdBook MathJax preview and the Pandoc EPUB conversion. You can read and edit the chapters without installing mdBook; mdBook is only needed to preview or publish the assembled website.

## Prerequisites

- Familiarity with Lean 4 declarations, terms, and tactic mode.
- Experience using basic Mathlib definitions and theorems.
- Comfort reading recursive definitions and mathematical induction.
