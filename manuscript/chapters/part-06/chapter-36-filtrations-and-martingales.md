# Chapter 36 — Filtrations and Martingales

> **Audience.** This chapter assumes familiarity with conditional expectation and probability measures. It develops filtrations, adapted processes, martingales, stopping times, and the main proof patterns behind convergence and optional-sampling results.

A stochastic process is a family of random variables indexed by time. To reason about what can be known at each time, probability theory equips the sample space with a growing family of σ-algebras called a filtration. A process adapted to a filtration uses no information from the future. A martingale is an integrable adapted process whose conditional expected future value equals its current value.

These definitions are compact, but the formal proof obligations are not. One must track the time order, measurability at each index, integrability at each time, and almost-everywhere equality of conditional expectations. Mathlib packages these properties so that convergence and optional stopping theorems can use the same interfaces rather than repeat low-level measure arguments.

This chapter emphasizes the design pattern: state the filtration once, prove adaptedness and integrability as separate facts, and use the martingale predicate for the conditional-expectation identity. The goal is to make large probability arguments modular and to expose exactly which hypotheses a theorem consumes.

## Learning objectives

By the end of the chapter, you should be able to:

- interpret a filtration as a monotone family of sub-σ-algebras;
- distinguish adaptation, integrability, and the martingale identity;
- recognize conditional expectations of one integrable variable as a martingale;
- state the differences among martingales, submartingales, and supermartingales;
- organize hypotheses for convergence and optional-sampling theorems;
- avoid confusing stopping times with arbitrary random time indices.

## 1. Filtrations: information that grows with time

Let `ι` be an ordered index type. A filtration `ℱ` on a measurable space `m₀` assigns a sub-σ-algebra `ℱ i` to each time `i`, subject to monotonicity:

\[
  i \leq j \quad\Longrightarrow\quad \mathcal{F}_i \leq \mathcal{F}_j.
\]

As time advances, more events become observable. Mathlib packages this as `Filtration ι m₀`; its fields expose the measurable spaces and the monotonicity proof. This is preferable to storing a family of measurable spaces and a separate monotonicity lemma, because any theorem receiving a `Filtration` can use the order interface uniformly.

The order on σ-algebras is inclusion of measurable sets, so the direction is easy to reverse accidentally. If `i ≤ j`, then `ℱ i ≤ ℱ j`: the earlier information is contained in the later information. Read the order as “every set measurable at time i is measurable at time j.”

```text
time:       0          1          2          3
            │          │          │          │
information ℱ₀ ───────▶ ℱ₁ ───────▶ ℱ₂ ───────▶ ℱ₃
            observable events accumulate over time
```

The natural filtration of a process is generated by what the process has observed up to a given time. It is the smallest filtration with respect to which the process is adapted. This is useful when the argument should depend only on observations made by the process itself. In other settings, a larger filtration models external information, such as a market's public information or a signal available to an observer.

Some theorems require every measure trimmed to a filtration stage to be σ-finite. Mathlib collects this property in `SigmaFiniteFiltration μ ℱ`. For probability measures, finiteness often makes this condition routine, but it remains part of the theorem's mathematical context. Avoid assuming that the word “filtration” itself includes every measure condition needed by integration results.

## 2. Adapted processes

Let `u : ι → Ω → E` be a process. It is adapted to `ℱ` if, at every time `i`, the random variable `u i` is strongly measurable with respect to `ℱ i`. Mathlib calls this property `Adapted ℱ u`.

Adaptedness is a time-indexed measurability condition. It does not imply integrability, boundedness, or any relationship between values at different times. It only states that the value at time `i` is determined measurably by the information available then.

```text
u₀ measurable with respect to ℱ₀     u₁ measurable with respect to ℱ₁
              │                                   │
              ▼                                   ▼
        no future data at 0                  no future data at 1
```

This distinction matters in Lean because the type of a process is just a function of the index into random variables. The filtration does not alter the codomain or automatically attach proof fields to each value. `Adapted ℱ u` is a proposition layered over that function, and each theorem lists it when required.

The term “predictable” describes a stronger and different notion in stochastic-process theory: roughly, a process's value at a time is determined by information from before that time. Do not replace adaptation with predictability or infer predictability from adaptation. For martingales and the basic results in this chapter, adaptation is the usual requirement.

## 3. Martingales and their conditional identity

A real-valued process `u` is a martingale with respect to measure `μ` and filtration `ℱ` when its values are integrable, it is adapted, and for all `i ≤ j`,

\[
  \mathbb{E}[u_j \mid \mathcal{F}_i] = u_i
  \quad\text{almost surely}.
\]

Mathlib packages this predicate as `Martingale u ℱ μ`. The equality is almost everywhere because conditional expectation is unique only up to null sets. A proof should use the predicate rather than unfolding it repeatedly, then provide the separate integrability, adaptation, and conditional-expectation facts at the point where the martingale is constructed.

The equation formalizes the fair-game intuition: given current information, the expected value at any later time equals the current value. It says nothing about each individual future outcome. A martingale can fluctuate substantially; only the conditional average is preserved.

For a submartingale, the conditional expected future value is at least the current value. For a supermartingale, it is at most the current value. These order variants support processes with upward or downward drift. The definitions share the same information and integrability discipline, so proofs can often reuse results after choosing the correct order direction.

The direction of an inequality is a common source of error. A process with nonnegative conditional drift is a submartingale under the conventional definition, while a process with nonpositive conditional drift is a supermartingale. Translate the theorem statement into the conditional-expectation equation before selecting a Mathlib predicate.

## 4. Worked example: conditioning one variable through time

Let `X` be an integrable random variable and let `ℱ` be a filtration. Define the process

\[
  M_i = \mathbb{E}[X \mid \mathcal{F}_i].
\]

Each value is measurable with respect to `ℱ i`, so the process is adapted. If `i ≤ j`, the filtration is monotone, so `ℱ i ≤ ℱ j`. The tower property then gives

\[
  \mathbb{E}[M_j \mid \mathcal{F}_i]
  = \mathbb{E}[\mathbb{E}[X\mid\mathcal{F}_j]\mid\mathcal{F}_i]
  = \mathbb{E}[X\mid\mathcal{F}_i]
  = M_i.
\]

Thus the conditional-expectation process is a martingale. Mathlib exposes this construction as `martingale_condExp` (with the assumptions on the integrable variable, filtration, and measure made explicit by its statement).

This is a model proof for the library predicate. Do not prove the martingale identity by manipulating a pointwise formula for every outcome. Instead, use the tower theorem in the almost-everywhere equality form. The adaptedness and integrability components follow from the corresponding conditional-expectation theorems.

This example appears throughout probability. The process is the best prediction of a fixed future quantity using progressively richer information. The martingale property says that revising a conditional prediction as information arrives does not create a systematic conditional gain.

## 5. Worked example: sums of martingale differences

Suppose `D i` is an integrable process such that each `D i` is measurable at time `i+1` and has conditional expectation zero given time `i`. Define partial sums by

\[
  S_0 = 0, \qquad S_n = \sum_{i<n} D_i.
\]

The intended result is that `S` is a martingale. The proof separates into three arguments. First, each partial sum is integrable because it is a finite sum of integrable variables. Second, it is adapted because every summand included by time `n` is measurable with respect to `ℱ n`, using filtration monotonicity. Third, for `n ≤ m`, the difference `S_m - S_n` is the finite sum of increments from `n` through `m-1`; conditioning each increment on `ℱ n` gives zero by the tower property and the zero conditional-mean assumption at its preceding time.

The resulting identity is

\[
  \mathbb{E}[S_m \mid \mathcal{F}_n] = S_n.
\]

Formalizing this efficiently relies on earlier chapters' finite-sum and linearity techniques. It is usually best to prove a lemma for one increment, establish the finite-sum conditional-expectation formula, and then use the martingale constructor or predicate. Avoid expanding the sum and applying integral definitions term by term inside the final proof.

The indexing convention deserves attention. If `D i` is revealed at time `i+1`, then it need not be measurable at time `i`. The partial sum through time `n` should include only increments already revealed by `n`. Off-by-one errors often appear as a failed adaptedness goal rather than a failed martingale equation.

## 6. Bounded transformations and useful constructions

Many martingale constructions begin by applying a conditional expectation, summing differences, or applying a measurable transformation. The transformation must preserve the required properties. For example, linear combinations of martingales remain martingales when integrability holds; sums are handled through linearity of conditional expectation. A nonlinear transformation generally does not preserve the martingale identity, though convex functions lead to submartingale results under suitable integrability assumptions.

Do not infer that a function of a martingale is itself a martingale merely because the function is measurable. Measurability can preserve adaptation, but the conditional-expectation equation needs an independent argument. For convex transformations, conditional Jensen inequalities are the relevant interface and typically give a submartingale inequality rather than equality.

A process's natural filtration is often a useful default when no extra information is present. But enlarging the filtration can change whether the process is a martingale: the conditional expectation given more information may differ. This is not a formal nuisance; it captures the fact that information can reveal a predictable trend.

## 7. Stopping times and stopped processes

A stopping time is a random time whose occurrence by time `i` can be decided using the information available at time `i`. In discrete time, the event `{τ ≤ i}` must be measurable with respect to `ℱ i` for every `i`. A stopping time therefore depends on the filtration, not just on a function from outcomes to times.

Given a process `u` and a stopping time `τ`, the stopped process evaluates `u` at the earlier of the current time and `τ`. Intuitively, after stopping, the value is frozen. Constructing this process requires an appropriate order on the index type and often finite or bounded stopping-time assumptions. The precise Lean representation of stopping times is type-dependent; in discrete-time APIs, extended naturals such as `WithTop ℕ` may be used to represent an infinite stopping time.

Optional stopping theorems do not say that every stopped martingale preserves expectation without qualifications. Standard safe forms assume bounded stopping times or impose uniform integrability and related hypotheses. Optional sampling results for submartingales may yield inequalities. The hypotheses prevent strategies that exploit unbounded stopping or nonintegrable tails.

When formalizing a stopping argument, prove in this order: the stopping-time measurability condition; adaptedness of the stopped process; integrability of the stopped values; and then the relevant optional-sampling theorem. A theorem application should be the final step, not the place where all these obligations are discovered at once.

The stopping time type also affects case analysis. If `τ` can be infinite, split the finite and infinite cases only when the theorem requires it. Do not coerce an extended natural into a natural index without proving finiteness. In many bounded optional-stopping applications, the bound supplies the finiteness needed to simplify the type-level representation.

The next chapter develops these obligations into a full optional-sampling argument, including the distinction between stopping-time measurability and boundedness. This chapter keeps stopping at the level of a first encounter with the idea; use Chapter 37 when the proof goal compares expected values at random times.

## 8. Martingale convergence

A martingale is not guaranteed to converge just because its conditional expectations are stable. Convergence theorems require additional control, commonly expressed through boundedness in L¹, a uniform-integrability condition, or a submartingale hypothesis with an appropriate expectation bound. The exact assumptions depend on the theorem and index type.

Mathlib's martingale convergence results provide almost-everywhere convergence under stated hypotheses. One should read the theorem as a package of analytical conditions, not as an automatic consequence of the `Martingale` predicate. The formal proof has two layers: first establish the probabilistic assumptions such as adaptedness and integrability bounds; then invoke the convergence result to obtain an almost-everywhere limit or convergence statement.

There are two distinct outcomes that should not be conflated. Almost-everywhere convergence gives a limit along almost every sample point. Convergence in L¹ or Lᵖ is stronger and requires a norm estimate or uniform integrability. A theorem about one mode of convergence does not silently give another.

The library interface benefits from stating bounds in a form that can be reused. If each `u i` has an L¹ norm bounded by a common constant, prove that property once and pass it to the convergence theorem. If the mathematical argument establishes uniform integrability instead, use the theorem formulated for that condition rather than attempting to derive a pointwise bound that is not true.

Chapter 38 develops these convergence assumptions in detail. In particular, it separates the upcrossing argument for almost-everywhere convergence from the uniform-integrability hypothesis needed for L¹ convergence, and explains how the terminal filtration determines the limit's measurability.

## 9. A proof workflow

1. Choose the time index type and state its order explicitly.
2. Define the filtration and verify monotonicity in the direction `ℱ i ≤ ℱ j` when `i ≤ j`.
3. Prove process adaptation separately from integrability.
4. State each conditional-expectation identity as an almost-everywhere equality.
5. Use `condExp_condExp_of_le` to simplify nested conditioning.
6. Construct martingales from conditional expectations or martingale differences using linearity and finite sums.
7. Before applying convergence or optional-stopping results, list the precise boundedness, integrability, or uniform-integrability assumptions.
8. Keep the filtration attached to every stopping-time claim; “stopping time” is relative to information.

This order makes failures local. A failed adaptedness proof usually indicates an index or measurability issue; a failed martingale equation usually indicates a conditioning-order or tower-property issue; a failed convergence application usually indicates a missing analytic bound.

## 10. Common failure modes

### The filtration order is reversed

For `i ≤ j`, information grows as `ℱ i ≤ ℱ j`. Check this before using adaptedness monotonicity or the tower property.

### Adaptedness is treated as integrability

Adaptedness is measurability at each time. The martingale predicate also needs integrability; prove both.

### The martingale equation is stated pointwise

Conditional expectation identities are almost everywhere. Use the measure-indexed equality form.

### A submartingale inequality points the wrong way

Translate the definition into “conditional future value versus current value” before selecting `Submartingale` or `Supermartingale`.

### A transformed process is assumed to remain a martingale

Measurable transformations preserve measurability, but not generally conditional means. Use linearity, conditional Jensen, or a dedicated theorem.

### Optional stopping is applied without control

Unbounded stopping times and uncontrolled tails can invalidate expectation preservation. Supply boundedness or the exact integrability condition in the theorem statement.

### Almost-everywhere convergence is reported as norm convergence

Pointwise probabilistic convergence and L¹ convergence are different conclusions. Select the theorem that matches the required mode.

## Summary

A filtration is an increasing family of information σ-algebras. An adapted process is measurable at each time using the information available then. A martingale is an integrable adapted process whose conditional future value equals its current value almost surely; submartingales and supermartingales replace equality with an inequality. Conditional expectations of a fixed integrable variable form a martingale by the tower property. Stopping and convergence theorems require additional hypotheses, so formal proofs should establish adaptation, integrability, time bounds, and convergence control explicitly.
