# Chapter 31 — Measurable Functions and Almost-Everywhere Reasoning

> **Audience.** This chapter assumes familiarity with topology, sets, and basic probability or measure theory. It develops the measurable-space interfaces that let Lean reason about measures, measurable functions, and properties that hold almost everywhere.

Measure theory separates the structure of measurable sets from the structure of open sets. A measurable space records which sets can be measured; a measure assigns sizes to those sets; and a measurable function pulls measurable sets back to measurable sets. In applications, many statements only need to hold outside a set of measure zero. Mathlib represents that notion with a filter, so almost-everywhere reasoning composes naturally with the filters used for convergence in Chapter 24.

The main formalization task is to choose the right level of measurability. `Measurable` is a global property of a function, while `AEMeasurable` and `AEStronglyMeasurable` allow changes on null sets and are often the interfaces required by integration. This chapter develops those distinctions and shows how to keep measure-space assumptions visible.

## Learning objectives

By the end of the chapter, you should be able to:

- distinguish measurable spaces from topological spaces and identify their Borel connection;
- prove measurability through composition and measurable-set closure;
- work with measures and restricted measures without unfolding their definitions;
- use almost-everywhere equality and quantification as filter statements;
- choose between `Measurable`, `AEMeasurable`, `StronglyMeasurable`, and `AEStronglyMeasurable`.

## 1. Measurable spaces are a separate structure

A `MeasurableSpace α` is a σ-algebra on a type `α`. It declares a collection of subsets closed under complements and countable unions, along with the empty set and universal set. The adjective “countable” matters: unlike a topology, a σ-algebra is not required to be closed under arbitrary unions.

The measurable sets are propositions of type `MeasurableSet s`. Closure lemmas compose the basic operations: measurable complements, countable unions, and countable intersections. The countability requirement is represented by an instance such as `[Countable ι]` when taking a union indexed by `ι`.

```lean
example {α ι : Type*} [MeasurableSpace α] [Countable ι]
    (s : ι → Set α) (hs : ∀ i, MeasurableSet (s i)) :
    MeasurableSet (⋃ i, s i) := by
  exact MeasurableSet.iUnion hs
```

A type can carry both a topology and a measurable space. The Borel measurable space is generated by the open sets; standard spaces such as `ℝ` have this compatible instance. Keeping these structures distinct is important in abstract theorems: continuity talks to topology, while measurability talks to a σ-algebra. The `BorelSpace` interface states that the measurable structure agrees with the one generated from the topology.

For a discrete measurable space, every subset is measurable. For other measurable spaces, a set need not be measurable even if it is a well-formed `Set α`. A theorem about `μ s` may therefore ask for measurability of `s` before it can use countable additivity or restriction formulas.

Many measurable spaces are generated by a chosen family of sets. The Borel σ-algebra is generated by open sets; a product measurable space is generated by measurable rectangles. In a proof, this can reduce an infinite condition over all measurable sets to a generating family, provided the generation theorem has the required closure properties. The generated-space interface is preferable to unpacking a σ-algebra as a collection of sets and reproving its axioms.

Some statements use a σ-algebra different from the default instance on a type. Mathlib provides notation for writing measurability relative to an explicitly named measurable space. This is useful when a function is measurable with respect to a sub-σ-algebra, or when comparing a coarse and a fine notion of observability. Make the domain σ-algebra visible in the theorem statement; otherwise typeclass inference may silently select the ambient instance.

## 2. Functions pull measurable sets back

For measurable spaces on `α` and `β`, a function `f : α → β` is measurable when the preimage of every measurable subset of `β` is measurable in `α`. The direction is always preimage. Direct images do not generally preserve measurability without additional assumptions.

```text
measurable set B in β  ── preimage under f ──▶  measurable set f ⁻¹' B in α
```

This definition supports composition. If `f` is measurable from `α` to `β` and `g` is measurable from `β` to `γ`, then `g ∘ f` is measurable:

```lean
example {α β γ : Type*} [MeasurableSpace α] [MeasurableSpace β]
    [MeasurableSpace γ] {f : α → β} {g : β → γ}
    (hf : Measurable f) (hg : Measurable g) :
    Measurable (g ∘ f) := by
  exact hg.comp hf
```

The proof reflects the preimage calculation `(g ∘ f) ⁻¹' s = f ⁻¹' (g ⁻¹' s)`. Usually, apply the composition theorem rather than rewriting preimages manually. The pointwise form `Measurable.fun_comp` is convenient when the goal is written as `fun x => g (f x)` instead of explicit composition.

For functions into a Borel space, continuity is a standard source of measurability. In an abstract measurable codomain with no relationship to a topology, continuity alone says nothing about measurable preimages. Check the Borel-space assumptions before asking Lean to synthesize a measurability fact from continuity.

Product codomains are handled componentwise. A function into `β × γ` is measurable when its two coordinate functions are measurable, and measurable operations on products then follow by composition. This mirrors ordinary analysis, where a vector-valued function can be checked coordinate by coordinate in a finite product. For an infinite product, the σ-algebra and topology assumptions determine whether the same argument is available; do not transfer a finite-product theorem without checking them.

## 3. Constructing measurable functions

Measurable functions are closed under many familiar operations. Constant functions are measurable. Coordinate projections and pairing maps are handled through product measurable spaces. Algebraic operations on a Borel topological ring are measurable under the standard compatibility assumptions, so measurable real-valued functions can be added and multiplied using the relevant closure theorems.

For piecewise definitions, prove that the branch set is measurable and that each branch is measurable. The `Measurable.ite` and piecewise APIs capture this pattern. This is often clearer than proving the preimage condition separately for every set.

The `measurability` tactic can discharge routine goals after the function has been decomposed into known operations. It is most useful at the end of a proof, once the relevant hypotheses are present. If it fails, inspect the first unknown component: the problem may be a missing measurable-space instance, an unproved measurability fact for one branch, or a target type that is not using its Borel measurable space.

Do not treat the tactic as a substitute for stating the mathematical structure. A theorem should still expose the measurable assumptions it relies on. In particular, a custom function defined by cases may need an explicit lemma before automation can recognize the measurable pieces.

## 4. Measures and measurable sets

A measure `μ : Measure α` assigns values in `ℝ≥0∞`, the extended nonnegative reals, and is countably additive on pairwise disjoint measurable sets. Mathlib extends the value of a measure to arbitrary sets, but formulas involving countable additivity or restriction may still require measurability assumptions.

The codomain `ℝ≥0∞` is intentional. It accommodates infinite measure and avoids partial arithmetic in the definition. When a finite real value is needed, the proof must establish finiteness before converting an extended value to `ℝ`.

The restriction `μ.restrict s` measures sets only within `s`. On a measurable set `t`, the defining calculation simplifies to measuring `t ∩ s` with respect to `μ`. This is useful for integrals over a set: one can either integrate with respect to the restricted measure or use the set-integral notation from the integral API.

Measures can also be transported along measurable functions. The pushforward `Measure.map f μ` records the distribution seen after applying `f`. Its value on a measurable set is determined by the measure of the preimage, which makes measurability of `f` the key hypothesis. Choose `map` when the codomain measure is the object of interest; choose `restrict` when the domain is being limited to a measurable region.

This is the formal pattern behind a random variable: a probability space supplies the measure, and a measurable function sends outcomes into a value space. The distribution of the values is the pushforward measure. An event about the output is pulled back to an event about the input, so its probability is computed by measuring a preimage. This interpretation makes the direction of `Measure.map` and the preimage condition for `Measurable` reinforce one another.

## 5. Almost-everywhere statements are filter statements

Given a measure `μ`, the notation `∀ᵐ x ∂μ, P x` says that `P` holds for almost every `x`. The notation `f =ᵐ[μ] g` says that the functions agree outside a null set. These statements use the `ae` filter associated with the measure, so filter operations such as conjunction, implication, and eventuality have direct almost-everywhere counterparts.

For example, if `f =ᵐ[μ] g` and `g =ᵐ[μ] h`, then `f =ᵐ[μ] h`. The exceptional sets for the first two equalities are combined, and the union of two null sets remains null. The filter API carries this bookkeeping, avoiding explicit construction of exceptional sets.

Almost-everywhere equality is often the correct equality for measure-theoretic functions. Two functions can differ at individual points and still have the same integral if the set where they differ has measure zero. This is why `integral_congr_ae` is a central theorem in the next chapter.

Keep `MeasurableSet` separate from `NullMeasurableSet`. A null-measurable set agrees with a measurable set up to a null set; it need not itself belong to the original σ-algebra unless the measure space is complete. Many integration theorems accept null-measurable sets because their conclusions are unchanged by null modifications. A set-theoretic argument may still need actual measurability, so use the predicate required by the theorem instead of assuming the two notions coincide.

The difference between an everywhere statement and an almost-everywhere statement must remain explicit. From `∀ᵐ x ∂μ, P x`, one cannot infer `P x` for an arbitrary fixed `x` unless the measure gives the exceptional set no possible points or another hypothesis rules out failure there.

## 6. Measurable and almost-everywhere measurable

`Measurable f` is a global property. `AEMeasurable f μ` says that `f` agrees almost everywhere with a measurable function. It is the right interface when integration depends only on the almost-everywhere class and the original representative may be irregular on a null set.

For a topological target, `StronglyMeasurable f` says that `f` is a pointwise limit of simple functions. A simple function has finite range with measurable fibers. This approximation-based definition is adapted to the construction of the Bochner integral, whose target can be a complete normed vector space rather than only `ℝ`.

`AEStronglyMeasurable f μ` weakens strong measurability by allowing a modification on a null set. Mathlib's integral and integrability APIs often use this stronger target-aware notion rather than mere `AEMeasurable`. The distinction is useful: a measurable scalar-valued function may automatically be strongly measurable under second-countability assumptions, but arbitrary target spaces require more care.

Almost-everywhere measurability is especially useful after restricting to a completion of a measure space. A set can differ from a measurable set by a subset of a null set, and an almost-everywhere statement may ignore that difference. Ordinary measurability remains sensitive to the exact σ-algebra. Before replacing one with the other, check whether the theorem is stated for a completed measure, a completed measurable space, or only equality outside a null set.

The common implication is that strongly measurable functions are measurable when the target has suitable metrizable Borel structure. Conversely, measurability implies strong measurability under countability assumptions on the topological spaces. Check these assumptions before converting one property into the other.

## 7. Indicators and piecewise behavior

The indicator of a measurable set is a basic example of a measurable function. It takes one value on the set and zero outside. Indicators connect set operations to integrals: integrating an indicator measures the set, subject to the appropriate finiteness and codomain conventions.

Piecewise functions built from measurable branches and a measurable condition are also measurable. The proof typically has three named components: the measurable branch set, the measurability of the first function, and the measurability of the second function. Use the library's piecewise lemma to combine them.

This pattern scales to simple functions, which partition the domain into finitely many measurable fibers and assign a value to each fiber. Simple functions are not just convenient examples: they form the approximation basis for the strong measurability and integration theories. A proof about general functions can often be understood by first checking the claim for a simple function and then passing to a limit using the right convergence theorem.

## 8. A proof workflow

1. Identify the measurable-space instance on the domain and codomain.
2. Separate topological continuity from measurable preimage conditions; use Borel compatibility when passing between them.
3. Build measurability from closure lemmas and composition rather than expanding the definition repeatedly.
4. Use `MeasurableSet` for set hypotheses and keep countability explicit for countable unions.
5. Use `AEMeasurable` or `AEStronglyMeasurable` when null-set changes are allowed or integration is the goal.
6. Express almost-everywhere claims with `∀ᵐ` and `=ᵐ[μ]` so filter composition can manage exceptional sets.
7. Use restriction for a domain region and pushforward for a transformed distribution.

This order keeps the source of each assumption clear. A function may be continuous but not measurable for an unrelated σ-algebra, or measurable but not integrable. Keeping those predicates separate prevents typeclass assumptions from obscuring the analytic content.

## 9. Common failure modes

### A measurable-set argument uses arbitrary unions

Only countable unions are guaranteed by a σ-algebra. Supply the countability assumption or use a different generating argument.

### Continuity is expected to imply measurability automatically

Check that the measurable structures are Borel structures associated with the topologies.

### A pointwise conclusion is extracted from an almost-everywhere fact

The exceptional null set may contain the chosen point. Keep the conclusion almost everywhere unless additional hypotheses justify more.

### Measurability is used where strong measurability is required

For Bochner integration, check for `AEStronglyMeasurable`. Use separability or second-countability results to bridge from ordinary measurability when available.

### A function is modified on a null set but the proof unfolds the modification

Use the almost-everywhere equivalence API. Most measure-theoretic conclusions are invariant under such modifications.

2. Show that a countable union of measurable sets is measurable and identify the role of the countability instance.
3. State the assumptions under which a continuous map into a Borel space is measurable.
4. Prove transitivity of almost-everywhere equality by combining the corresponding filters.
5. Compare `AEMeasurable` and `AEStronglyMeasurable`. Give an example of why integration needs a target-aware notion.
6. Prove measurability of a piecewise function from a measurable set and measurable branch functions.
7. Explain the difference between restricting a measure and pushing it forward through a measurable map.

## Summary

Measurable spaces are σ-algebras, distinct from topological spaces but connected through Borel structures. Measurable functions pull measurable sets back, and composition plus closure lemmas provide the usual proof interface. Measures take values in `ℝ≥0∞`; restrictions and pushforwards model domain restrictions and transformed distributions. Almost-everywhere statements use the measure's `ae` filter. For integration, distinguish global measurability from `AEMeasurable` and `AEStronglyMeasurable`.
