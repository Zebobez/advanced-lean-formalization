# Chapter 46 — Measure-Preserving Dynamics and Ergodicity

> **Audience.** This chapter assumes familiarity with measure pushforwards, almost-everywhere equality, and invariant measures. It develops measure-preserving transformations, ergodicity, invariant functions, and Poincaré recurrence.

A measure-preserving transformation moves points while keeping the distribution unchanged. Ergodicity says that the only measurable sets invariant under the dynamics, up to null sets, are trivial: almost empty or almost the whole space. It is a formal expression of the idea that the system cannot be decomposed into smaller invariant regions of positive measure.

Mathlib builds ergodicity on top of the pushforward API. `MeasurePreserving f μ μ` packages measurability and preservation of `μ`; `Ergodic f μ` adds the almost-invariant-set condition. The resulting interface supports useful consequences, including that almost-everywhere invariant measurable functions are almost-everywhere constant and that finite measure-preserving maps are conservative.

This chapter focuses on these definitions and consequences rather than treating ergodicity as a synonym for convergence of averages. The proof obligations are about measure preservation and invariant sets. Any theorem about long-term averages must be selected separately with its exact hypotheses.

## Learning objectives

By the end of the chapter, you should be able to:

- state measure preservation using the pushforward measure;
- characterize ergodicity through almost-invariant sets;
- prove finite cyclic rotations are ergodic or nonergodic from their orbits;
- use the invariant-function consequence of ergodicity;
- apply conservativity and Poincaré recurrence under finite-measure assumptions;
- distinguish ergodicity from mixing and convergence of averages.

## 1. Measure-preserving maps

Let `f : α → β` be a map between measurable spaces with measures `μ` and `ν`. It is measure preserving when it is measurable and

\[
  \mathrm{Measure.map}(f,\mu)=\nu.
\]

For a self-map on one measured space, `MeasurePreserving f μ μ` means every measurable target set has the same measure as its preimage. This packages the two proof obligations—measurability and the pushforward equality—into one proposition.

The map need not be invertible. A noninvertible transformation can preserve a measure by merging points in a measure-balanced way. When the map is an equivalence, the measure-preserving property of the inverse can be derived from that of the forward map.

Composition is stable: if `f` preserves `μ` to `ν` and `g` preserves `ν` to `ξ`, then `g ∘ f` preserves `μ` to `ξ`. This lets a proof establish preservation for generators and then use algebraic composition for iterates. For a self-map, all powers preserve the same measure.

```text
state space α with μ ──f──▶ state space β with ν
         measure preserving means map f μ = ν
```

## 2. Ergodicity through invariant sets

A measure-preserving self-map `f` is ergodic with respect to `μ` if every null-measurable set `s` that is invariant almost everywhere,

\[
  f^{-1}(s)=^{\mu}_{\mathrm{ae}}s,
\]

is either null or conull. Mathlib defines `Ergodic f μ` as a structure extending measure preservation and this almost-invariant-set property.

The almost-everywhere form is essential. A set can change on a null subset under `f` without changing any probability-level behavior. Proving strict set equality is unnecessarily strong and may fail even when the ergodic statement is correct.

There is also a pre-ergodic predicate for the invariant-set condition without separately requiring measure preservation, and a quasi-ergodic predicate built over quasi-measure-preserving maps. Use `Ergodic` for the standard probability-preserving situation; the weakened variants are useful when only null sets need to be preserved.

Ergodicity does not mean every orbit is dense or every point visits every positive-measure set. It is a measure-level statement that rules out nontrivial invariant measurable subsets. Topological transitivity and pointwise orbit properties require additional assumptions.

## 3. Worked example: cyclic rotation on a finite space

Let the state space be `Fin n` with uniform probability measure, and let

\[
  T_k(x)=x+k\pmod n.
\]

This map is a permutation, so it preserves the uniform measure. Its orbits are the cosets of the subgroup generated by `k`. A set is invariant under `T_k` exactly when it is a union of these cycles. Therefore `T_k` is ergodic for the uniform measure exactly when it has a single orbit, equivalently when `gcd(k,n)=1`.

For `k=1`, the map is a single cycle. Any invariant subset containing one point must contain its successive images and therefore every point; the only invariant sets are empty and full. For `n=6` and `k=2`, there are two cycles, the even states and the odd states. The even states form a nontrivial invariant set of measure `1/2`, so the map is not ergodic.

In Lean, prove measure preservation from the permutation equivalence, then characterize invariant subsets through the orbit structure or finite case analysis. To establish nonergodicity, provide one measurable invariant set with measure strictly between zero and one. To prove ergodicity, show every invariant set is empty or full, then translate that exact finite statement to the almost-everywhere formulation.

## 4. Worked example: the identity map is not usually ergodic

The identity map preserves every measure. However, every measurable set is invariant under the identity. If the space contains a measurable set of positive measure whose complement also has positive measure, the identity is not ergodic.

For example, on `[0,1]` with Lebesgue probability measure, the interval `[0,1/2]` is invariant and has measure `1/2`. Thus measure preservation alone is far weaker than ergodicity.

This is a useful negative test in formal developments. If a proposed ergodicity theorem seems to follow from `MeasurePreserving` alone, check whether it has silently assumed that all measurable sets are trivial modulo null sets, or whether the intended conclusion was only quasi-measure preservation.

## 5. Invariant functions are constant almost everywhere

Ergodicity has a function-level consequence. If `g` is almost-everywhere strongly measurable and invariant under `f`,

\[
  g\circ f=g\quad\text{almost everywhere},
\]

then `g` is almost everywhere equal to a constant, under the codomain assumptions of the corresponding theorem. Mathlib provides `Ergodic.ae_eq_const_of_ae_eq_comp_ae` and related formulations for almost-everywhere equivalence classes.

This result is a powerful proof shortcut. Instead of classifying every level set of `g`, show that `g` is invariant and invoke the theorem. The underlying mathematical reason is that each measurable level set of an invariant function is an invariant set; ergodicity forces every such level set to have probability zero or one, which leaves no room for nontrivial variation.

The API may require a topological or measurable structure on the codomain and strong measurability of `g`. Match the theorem to the actual type: real-valued integrable functions, measurable finite-valued functions, and almost-everywhere equivalence classes can use different versions.

The converse viewpoint is useful when a direct function theorem is not available. If `g ∘ f = g` almost everywhere, then for every measurable set `B` in the codomain, the preimage `g⁻¹(B)` is invariant modulo a null set. Ergodicity makes each such preimage null or conull. For real-valued functions, applying this to a countable family of rational threshold sets can force the distribution of `g` to concentrate at one value. This route exposes the measurable-set argument and can be adapted to a codomain for which no packaged constant-function theorem is available.

Equality almost everywhere should be treated as the natural equality on this part of the subject. Rewriting by ordinary function equality may be too strong: two functions can disagree on a null set while representing the same measurable observable. Keep pointwise equalities for computational identities and switch explicitly to `=ᵐ[μ]` when null sets are permitted.

## 6. Conservativity and Poincaré recurrence

A self-map is conservative if every positive-measure measurable set contains a point that returns to the set after some positive number of iterations. For finite measure-preserving maps, Mathlib proves conservativity. The stronger Poincaré recurrence theorem says that almost every point in a measurable set of positive measure returns to that set infinitely often.

This theorem does not require ergodicity. It follows from finite measure preservation, while ergodicity is an additional restriction on invariant sets. The distinction is important: recurrence says typical points return to neighborhoods or sets; ergodicity says invariant measurable regions are trivial.

Mathlib's `MeasurePreserving.conservative` and the lemmas on `Conservative` formalize these results. For a topological space with second-countable topology and measurable open sets, `Conservative.ae_frequently_mem_of_mem_nhds` states that almost every point returns to each of its neighborhoods infinitely often.

The formal proof rests on finite measure: infinitely many disjoint returns of a positive-measure set would contradict preservation of total mass. In code, the recurrence theorem packages the combinatorial decomposition into first-return times and the measure estimate, allowing applications to focus on the invariant system rather than reproving the argument.

There is a hierarchy here. Conservativity is a set-level assertion excluding wandering sets of positive measure. Poincaré recurrence refines it into a statement about almost every point of a fixed measurable set. Neighborhood recurrence follows by applying recurrence to a countable neighborhood basis, which is why second-countability assumptions appear in topological formulations. When using a library theorem, inspect whether its conclusion is “there exists a return,” “infinitely many returns,” or “returns to every neighborhood”; these are related but not interchangeable without additional arguments.

Finite measure is sufficient, while infinite measure can behave differently. Translation by one on the integers with counting measure preserves measure but moves every point away from a singleton forever. This illustrates why the finite-measure hypothesis is structural, not a technical inconvenience that can be dropped after the theorem has been applied.

## 7. Ergodicity is not mixing

Ergodicity rules out nontrivial invariant sets, but it does not imply that correlations decay or that the distribution of `f^n(x)` approaches a limiting law. Mixing is a stronger asymptotic property. Likewise, ergodicity alone does not guarantee pointwise convergence of time averages for every integrable function unless an appropriate ergodic theorem is available and its hypotheses are met.

This distinction should be reflected in theorem statements. `Ergodic f μ` is about invariant sets. A result about convergence of averages concerns the sequence

\[
  \frac1N\sum_{n<N}g(f^n(x)),
\]

and needs an ergodic-average theorem plus integrability. Do not infer that limit merely from the definition of ergodicity.

Finite cyclic rotations give a quick comparison. A single cycle with uniform measure is ergodic, but a periodic system can still exhibit persistent oscillation in observables. Time averages may converge for finite systems, but that conclusion comes from finite orbit structure or a separate averaging theorem, not from a claim that trajectories themselves converge.

One can see the gap between ergodicity and mixing on a finite cycle. Let `f` rotate `n` states by one position and let `g` be the indicator of a single state. Along every orbit, `g(f^k(x))` is periodic, so the raw observable does not settle to a limit. Its time average does converge to `1/n`. The system is ergodic because there is one orbit, but correlations do not decay in the manner required for mixing. A formal proof should name which sequence is under study: point values, expectations, correlations, or Cesàro averages.

For analytic systems, the same separation leads to distinct interfaces. Measure preservation controls integrals under composition. Ergodicity simplifies invariant observables. A mixing theorem controls correlations as time tends to infinity. An ergodic theorem controls time averages almost everywhere. Choosing the theorem by the form of the target expression is often more effective than searching only for a theorem whose name contains “ergodic.”

## 8. Ergodicity and powers of a map

Measure preservation passes to every iterate of a measure-preserving self-map, but ergodicity need not. On `Fin 4`, rotation by one position is ergodic under the uniform measure because it is a single cycle. Its square rotates by two positions and splits the space into the even and odd states. The set of even states is invariant under the square and has measure `1/2`, so the square is not ergodic.

This example matters when translating statements about a time step into statements about a subsequence of times. Sampling every second iterate can introduce new invariant classes, even though the original dynamics is ergodic. In general, if the goal concerns `f^k`, prove ergodicity of that iterate or use a theorem with a precise power hypothesis; do not infer it from `Ergodic f μ` alone.

The finite proof separates naturally into three pieces: show the original rotation is a permutation preserving uniform measure; identify the orbit decomposition of the `k`-step rotation; and exhibit a nontrivial orbit union when the greatest common divisor is not one. This decomposition mirrors a good Lean proof: algebra on `Fin n`, measure preservation, and the ergodic-set criterion should be distinct helper lemmas.

## 9. Proof architecture for almost-invariant sets

An ergodicity proof often has two independent layers. The dynamical layer proves that a candidate set is invariant under the map, perhaps by rewriting its preimage. The measure-theoretic layer proves that an almost-invariant set has measure zero or full measure. Keeping these obligations separate prevents a proof from mixing pointwise orbit calculations with null-set arguments.

For a finite state space with uniform measure, there are no nonempty null sets. Almost-everywhere set equality reduces to ordinary equality, and ergodicity reduces to the statement that the action has one orbit. In an infinite probability space, this simplification disappears: one must allow exceptional states and reason with `ae` set equality. A proof that succeeds on a finite model is a valuable guide, but it is not a substitute for the measurable argument in the general theorem.

When a set is defined by a property `P`, unfold just enough to show that membership is preserved:

```text
x ∈ s  ── apply f ──▶  f x ∈ s
   │                         │
   └── invariance modulo a μ-null set ──┘
```

Then establish measurability of `s` and its preimage. The ergodicity hypothesis applies only after those obligations and the almost-everywhere invariance relation are available. In Lean, named intermediate facts for measurability, invariance, and measure triviality make this proof much easier to diagnose than a single tactic block that unfolds all three at once.

## 10. A proof workflow

1. State the source and target measures explicitly.
2. Prove measurability and the pushforward equality for measure preservation.
3. Express ergodicity as triviality modulo null sets of almost-invariant measurable sets.
4. For a nonergodicity proof, exhibit one nontrivial invariant set.
5. For an ergodicity proof, classify all invariant sets or use a theorem about invariant functions.
6. Use `Ergodic.ae_eq_const_of_ae_eq_comp_ae` when the goal is constancy of an invariant function.
7. For recurrence, establish finite measure preservation and apply conservativity or Poincaré recurrence.
8. Keep mixing and convergence-of-averages conclusions separate from ergodicity.

The finite examples can often be solved by orbit decomposition. In general spaces, the measurable-set formulation is more reliable than pointwise orbit arguments, because the theorem allows exceptional null sets and does not require every orbit to have the same behavior.

## 11. Common failure modes

### Measurability is omitted from measure preservation

`MeasurePreserving` packages both measurability and equality of pushforward measures.

### Invariance is stated pointwise

Ergodicity is defined modulo null sets. Use the almost-everywhere preimage equality.

### A nontrivial invariant set is overlooked

To disprove ergodicity, one positive-measure set with positive-measure complement is enough.

### Ergodicity is confused with topological transitivity

One is measure-theoretic; the other concerns topological orbit behavior.

### Ergodicity is used to claim mixing or average convergence

Those are stronger conclusions and need theorems with additional hypotheses.

### Recurrence is assumed to require ergodicity

Poincaré recurrence follows from finite measure preservation; ergodicity is not needed for the basic return statement.

Ergodicity acts on sets modulo null sets. Its invariant-function consequence
requires almost-everywhere strong measurability and a metrizable codomain.

```lean
import Mathlib.Dynamics.Ergodic.Function
import Mathlib.Dynamics.Ergodic.Conservative

open Filter MeasureTheory

theorem exercise_46_2_ergodic_set_is_ae_trivial
    {α : Type*} [MeasurableSpace α] {μ : Measure α} {f : α → α}
    (h : Ergodic f μ) {s : Set α}
    (hs : NullMeasurableSet s μ) (hinv : f ⁻¹' s =ᵐ[μ] s) :
    s =ᵐ[μ] ∅ ∨ s =ᵐ[μ] Set.univ :=
  h.toPreErgodic.ae_empty_or_univ hs hinv

theorem exercise_46_5_invariant_observable_is_ae_constant
    {α : Type*} [MeasurableSpace α] {μ : Measure α} {f : α → α}
    (h : Ergodic f μ) {g : α → ℝ}
    (hgm : AEStronglyMeasurable g μ) (hinv : g ∘ f =ᵐ[μ] g) :
    ∃ c, g =ᵐ[μ] fun _ => c :=
  h.ae_eq_const_of_ae_eq_comp_ae hgm hinv

theorem exercise_46_6_finite_measure_preserving_is_conservative
    {α : Type*} [MeasurableSpace α] {μ : Measure α} [IsFiniteMeasure μ]
    {f : α → α} (hf : MeasurePreserving f μ μ) :
    Conservative f μ :=
  hf.conservative
```

## Summary

Measure preservation means `Measure.map f μ = μ`. Ergodicity adds that every almost-invariant measurable set is null or conull. On finite cyclic spaces this reduces to a single orbit, while invariant measurable functions are almost everywhere constant. Finite measure preservation also yields conservativity and Poincaré recurrence. Ergodicity remains distinct from mixing and convergence of averages, so each long-term conclusion needs its own theorem and assumptions.
